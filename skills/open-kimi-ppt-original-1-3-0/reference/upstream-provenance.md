This directory is an installable SkillVerge adaptation of the upstream skill package. The Skill ID and three fixed installation-path examples in `SKILL.md` were renamed to `open-kimi-ppt-original-1-3-0` so it can coexist with the maintained variant. SkillVerge UI metadata was added with implicit invocation disabled. The upstream installer normally copies `editor/` and the patched WASM file into the installed skill; those files are included here without executing the installer.
